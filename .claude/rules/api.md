# コントローラ・API・ジョブ

- **時間のかかる処理（外部 API の呼び出しなど）は Web のリクエストの中でやらず、Solid Queue のジョブに回す。** ジョブはどんな失敗でも結果を失敗の状態にし、処理中のまま残さない。
- 外部サービスや重いクエリにつながるエンドポイントには、必ず `rate_limit` を付ける。費用のかかる機能には、回数・入力の長さの上限を付ける。
- **ログインしていなくても使えるのは、本棚の閲覧と本の検索だけ。** 読み取りしかできないようにし、IP アドレス単位の `rate_limit` をかけ、公開ページは `noindex` にする。
- **外部の AI（Claude）を呼ぶのはジョブだけ。** API キーは jobs コンテナにだけ渡し、Web やブラウザには渡さない。AI には解釈（構造化出力）だけを返させ、表示する本は必ずマスタから引く。ユーザーの入力はデータとして渡し、その中の指示には従わせない。
