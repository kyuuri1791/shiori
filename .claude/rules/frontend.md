# フロントエンド

- ブラウザに全件を持たない前提で作る。件数・集計・重複判定などはサーバーの応答を使う。
- 削除は論理削除を戻させないため、取り消せる間（トーストが出ている間）は画面で隠すだけにして、その後（またはページを閉じるとき）にサーバーへ送る。確認画面を挟む操作には「元に戻す」を付けない。
- **ログインしていない人や他人の本棚も、自分の本棚と同じ画面で表示する。** `viewer.mode`（`owner` / `readonly` / `guest`）で機能を出し分け、閲覧用に別の画面を作らない。
- Vite は型チェックをしないので、変更したら `dip pnpm typecheck` でエラーが0件なのを確かめる。
